# K3s air-gap image licenses

This package is an aggregate of the unmodified container images published in
the upstream K3s air-gap archive. Each embedded image remains subject to its
own upstream copyright notices and license terms; those terms are available
inside the corresponding image filesystem. The exact image inventory for this
archive is installed as `k3s-images.txt` next to this file.

The K3s project files distributed alongside the archive are licensed under
Apache-2.0 and are accompanied by `LICENSE.k3s`. The package metadata uses
`LicenseRef-K3s-Airgap-Bundle` because no single SPDX license expression can
accurately describe the aggregate image archive.
